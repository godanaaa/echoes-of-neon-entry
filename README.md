# ECHOES OF NEON

**The city remembers what you do.** Nova Haven has gone dark. As courier Kade Ryder, trace the blackout with Mira Vale, fight security crews, drive the night roads, and use Echo Vision to uncover the signal hidden beneath the city.

## How to play

WASD move or steer · Shift sprint · Space hop · Mouse aim · Click fire · E interact / enter or exit a vehicle · F melee · Q Echo Vision · R reload · 1 / 2 / 3 weapons · M map · P / Esc pause · N audio.

Follow each short mission marker, gather Echo fragments, and return to the Safehouse beacon to spend credits on upgrades. Echo Vision reveals hidden fragments and hostile signals.

## Run it

Open `game/index.html` in a modern desktop browser; all game code and audio are local. Use `?seed=N` for a repeatable city state. Capture-ready scenes use `?shot=start`, `?shot=play`, `?shot=echo`, and `?shot=end`.
